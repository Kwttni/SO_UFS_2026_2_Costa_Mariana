# Redes de Computadores

## O que é uma rede de computadores?

Uma rede de computadores é um conjunto de dispositivos conectados para permitir a comunicação e o compartilhamento de informações e recursos. Os dispositivos podem incluir computadores, servidores, celulares, impressoras e outros equipamentos de rede.

## O que é um endereço IP?

O endereço IP identifica um dispositivo dentro de uma rede. Ele permite que os dados sejam encaminhados para o destino correto. Existem versões como IPv4 e IPv6, que utilizam diferentes formatos de endereçamento.

## O que é um roteador?

O roteador é responsável por encaminhar pacotes de dados entre redes diferentes. Ele analisa informações de destino e escolhe uma rota para que os dados possam chegar ao dispositivo ou rede correspondente.

## O que é um switch?

O switch conecta dispositivos dentro de uma mesma rede local. Ele recebe quadros de dados e os encaminha para a porta associada ao dispositivo de destino, reduzindo transmissões desnecessárias.

## O que é o protocolo TCP?

TCP é um protocolo utilizado para comunicação confiável entre dispositivos. Ele estabelece uma conexão, controla a entrega dos dados e pode retransmitir informações quando ocorre perda durante a transmissão.

## O que é o protocolo UDP?

UDP é um protocolo de transporte que não estabelece uma conexão da mesma forma que o TCP. Ele possui menor sobrecarga e pode ser utilizado em aplicações que priorizam velocidade e baixa latência.

## O que é DNS?

DNS é o sistema utilizado para associar nomes de domínio a endereços IP. Dessa forma, usuários podem acessar serviços utilizando nomes mais fáceis de memorizar em vez de informar diretamente um endereço IP.

## Exemplo de fluxo

Dispositivo → switch ou ponto de acesso → roteador → outras redes → servidor de destino.
