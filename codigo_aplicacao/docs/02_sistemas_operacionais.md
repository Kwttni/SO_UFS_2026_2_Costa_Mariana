# Sistemas Operacionais

## O que é um sistema operacional?

Um sistema operacional é o software responsável por administrar os recursos de um computador e fornecer serviços para os programas. Ele atua como uma camada entre o hardware e as aplicações.

## O que é um processo?

Um processo é um programa em execução. Ele possui recursos próprios, como espaço de memória e informações de execução, que são administrados pelo sistema operacional.

## O que é uma thread?

Uma thread representa uma linha de execução dentro de um processo. Um processo pode possuir várias threads que compartilham recursos do mesmo processo e podem executar tarefas de forma concorrente.

## O que é gerenciamento de memória?

O gerenciamento de memória controla como a memória principal é utilizada pelos processos. O sistema operacional deve distribuir espaço, acompanhar áreas ocupadas e liberar memória quando os recursos deixam de ser necessários.

## O que é memória virtual?

Memória virtual é um mecanismo que permite ao sistema operacional utilizar uma combinação de memória física e armazenamento para fornecer aos processos um espaço de endereçamento maior e mais organizado.

## O que é escalonamento?

Escalonamento é o processo de decidir qual processo ou thread deve utilizar o processador. O sistema operacional utiliza algoritmos de escalonamento para organizar a execução das tarefas.

## O que é um sistema de arquivos?

O sistema de arquivos organiza e controla como os dados são armazenados e recuperados em dispositivos de armazenamento. Ele define estruturas para arquivos, diretórios, permissões e outras informações.

## Exemplo de fluxo

Aplicação → chamada ao sistema → sistema operacional → hardware → resultado para a aplicação.
