# Inteligência Artificial

## O que é inteligência artificial?

Inteligência artificial é uma área da computação dedicada ao desenvolvimento de sistemas capazes de realizar tarefas que normalmente exigem algum tipo de capacidade associada à inteligência humana, como reconhecimento de padrões, classificação e geração de conteúdo.

## O que é aprendizado de máquina?

Aprendizado de máquina, ou Machine Learning, é uma abordagem em que algoritmos aprendem padrões a partir de dados para realizar previsões, classificações ou outras tarefas.

## O que é aprendizado supervisionado?

No aprendizado supervisionado, o modelo recebe exemplos de entrada associados a respostas conhecidas. Esses exemplos são utilizados durante o treinamento para aprender uma relação entre entradas e saídas.

## O que é aprendizado não supervisionado?

No aprendizado não supervisionado, os dados não possuem necessariamente respostas previamente definidas. O algoritmo pode procurar estruturas, agrupamentos ou padrões existentes no conjunto de dados.

## O que é treinamento?

Treinamento é a etapa em que os parâmetros de um modelo são ajustados com base nos dados disponíveis. O objetivo é fazer com que o modelo aprenda padrões úteis para a tarefa proposta.

## O que é inferência?

Inferência é a utilização de um modelo já treinado para produzir uma previsão ou resposta a partir de uma nova entrada.

## O que é uma rede neural?

Uma rede neural é um modelo composto por unidades organizadas em camadas que realizam operações matemáticas sobre os dados. Durante o treinamento, seus parâmetros são ajustados para representar padrões presentes nos exemplos.

## O que é Deep Learning?

Deep Learning é uma área do aprendizado de máquina que utiliza redes neurais com múltiplas camadas. Essas arquiteturas podem ser utilizadas em tarefas como processamento de imagens, áudio e linguagem natural.

## Exemplo de fluxo

Dados → pré-processamento → treinamento → modelo treinado → nova entrada → inferência → resultado.
