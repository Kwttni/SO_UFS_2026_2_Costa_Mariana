# Banco de Dados

## O que é um banco de dados?

Um banco de dados é uma coleção organizada de informações que pode ser armazenada, consultada e modificada por sistemas de software. Ele permite estruturar dados para facilitar seu gerenciamento.

## O que é um SGBD?

Um Sistema de Gerenciamento de Banco de Dados, ou SGBD, é um software utilizado para criar, armazenar, consultar e administrar bancos de dados. Ele também pode controlar acesso, integridade e concorrência.

## O que é uma tabela?

Em um banco de dados relacional, uma tabela organiza informações em linhas e colunas. Cada linha representa um registro e cada coluna representa um atributo desse registro.

## O que é uma chave primária?

A chave primária identifica de forma única cada registro de uma tabela. Ela não deve possuir valores duplicados e normalmente é utilizada para distinguir uma linha das demais.

## O que é uma chave estrangeira?

A chave estrangeira é um atributo utilizado para estabelecer uma relação entre tabelas. Ela normalmente referencia a chave primária de outra tabela.

## O que é SQL?

SQL é uma linguagem utilizada para trabalhar com bancos de dados relacionais. Com ela é possível realizar operações como consulta, inserção, atualização e exclusão de dados.

## O que é uma consulta SELECT?

A instrução SELECT é utilizada para consultar dados. Ela pode selecionar determinadas colunas, aplicar filtros, ordenar resultados e combinar informações de diferentes tabelas.

## O que é normalização?

Normalização é um processo de organização dos dados em estruturas relacionais para reduzir redundâncias e evitar determinados problemas de inserção, atualização e exclusão.

## Exemplo de fluxo

Aplicação → consulta SQL → SGBD → tabela/índice → resultado → aplicação.
